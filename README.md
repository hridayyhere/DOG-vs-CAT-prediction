# DOG-vs-CAT-prediction
# Dog vs. Cat Image Classification
A deep learning model to classify images as dog or cat using a Convolutional Neural Network (CNN).
Project Overview
This project implements a CNN to distinguish between dogs and cats from images.
✅ Built using TensorFlow/Keras 
✅ Trained on Kaggle Dogs vs Cats dataset 
✅ Achieved ~85% accuracy on validation data
✅ Includes training notebook, model file, and inference script
 Features
Image preprocessing and data augmentation

CNN model architecture

Training with early stopping + checkpointing

Model evaluation (accuracy, confusion matrix, sample predictions)

Inference function to predict on custom images

🏗️ Tech Stack
Python 3.x

TensorFlow / Keras (or PyTorch)

NumPy, Matplotlib, scikit-learn
